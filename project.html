03 WHAT I'LL SHOW
01

StockPilot

A modern inventory management dashboard designed to help businesses track products, stock levels and inventory activity.

02

The story

I built StockPilot to provide a simple and organized way to manage inventory, monitor stock levels and keep track of product activity in one place.

03

Technologies

I used HTML, CSS, and JavaScript, along with responsive design techniques, to create interfaces that work seamlessly across desktop, tablet, and mobile devices. I implemented interactive features using JavaScript event handling, including clicks, form submissions, navigation, and login interactions. I also used Local Storage to persist data and maintain application state
